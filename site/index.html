agent-promotion-lab · bible

From sandbox to production: a promotion pipeline for untrusted agents

One EKS cluster, three trust zones (sbx, staging, prod). An agent ships as a signed bundle, runs in a deny-all sandbox, earns wider permissions only through gates, and can be demoted automatically. OpenShell governs what each agent may call; Agent Substrate carries large fleets of stateful agents. One policy source compiles to both.
